Apa Itu Memory Card?

Memory Card adalah permainan mencocokkan kartu berpasangan. Tujuannya melatih ingatan, konsentrasi, dan ketelitian 😆.

Cara memainkan:

  1. Pilih tingkat kesulitan (misal: Easy 3x4, Medium 4x4, Hard 6x4).
  2. Klik tombol Mulai untuk mengacak kartu dan memulai permainan.
  3. Klik kartu untuk membukanya, cari pasangan yang sama.
  4. Cocokkan semua pasangan untuk menyelesaikan permainan 🎉.

Fitur:

  • 🔀 Tombol Hint untuk melihat kartu.
  • ⏱️ Timer & jumlah langkah otomatis dihitung.
  • 🏆 Setelah selesai, tampil langkah & waktu.
